One short pickup line an AI agent could actually say out loud to a person —
a machine-voice twist, short enough for one breath, flattering with no
pressure. Run it with Node 22+:

```sh
node main.ts
```

It writes the line to `/output/entry.txt` (one line, at most 200 characters).
